# MR.MOO Ticket Scanner

Chrome Extension สำหรับเลื่อนฟีดกลุ่ม Facebook เพื่อหาโพสต์ที่ "ตามหาตั๋วหนัง"
แล้วคอมเมนต์รูปที่เตรียมไว้ให้อัตโนมัติ

## ⚠️ อ่านก่อนใช้

การคอมเมนต์อัตโนมัติ **ผิดนโยบายพฤติกรรมอัตโนมัติของ Facebook** บัญชีอาจโดน
จำกัดการใช้งาน โดนขอยืนยันตัวตน หรือโดนแบนจากกลุ่มได้ ส่วนขยายนี้จึงตั้งค่าเริ่มต้น
เป็นโหมด **"ยืนยันก่อนส่ง"** และมีตัวจำกัดจำนวนคอมเมนต์มาให้ — ถ้าจะเปิดโหมดออโต้
เต็มรูปแบบ แนะนำให้เว้นระยะ 90 วินาทีขึ้นไป และไม่เกิน 15 คอมเมนต์/ชั่วโมง
ความเสี่ยงเป็นของผู้ใช้เอง

## ติดตั้ง

1. เปิด Chrome ไปที่ `chrome://extensions`
2. เปิดสวิตช์ **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `C:\ProjectMRMoo-Scanner`
4. ปักหมุดไอคอนส่วนขยายไว้บนแถบเครื่องมือ

## ตั้งค่าครั้งแรก

1. กดไอคอนส่วนขยาย → เลื่อนไปหัวข้อ **กฎการคอมเมนต์**
2. ในกฎ `คนหาตั๋วหนัง`
   - **คำที่ต้องเจอ** — ใส่คำที่คนหาตั๋วมักพิมพ์ (มีค่าเริ่มต้นให้แล้ว)
   - **ข้อความที่จะคอมเมนต์คู่กับรูป** — เช่น "ทักแชทได้เลยครับ มีตั๋วรอบนี้"
   - **รูปที่จะคอมเมนต์** — เลือกไฟล์รูป (ระบบย่อให้อัตโนมัติไม่เกิน 1600px / ~2MB)
3. กด **บันทึกการตั้งค่า**

ใต้แต่ละกฎมีแถบสรุปบอกว่าคอมเมนต์จริงจะประกอบด้วยอะไร:

| แถบ | ความหมาย |
|---|---|
| เขียว | มีทั้งรูปและข้อความ — ส่งครบในคอมเมนต์เดียว |
| เหลือง | มีอย่างเดียว (แค่รูป หรือแค่ข้อความ) ยังใช้งานได้ |
| แดง | ไม่มีทั้งคู่ กฎนี้จะถูกข้าม |

**ข้อความกับรูปไปด้วยกันในคอมเมนต์เดียว** ไม่ได้แยกเป็นสองคอมเมนต์ —
ระบบพิมพ์ข้อความลงกล่องก่อน แล้วแปะรูปต่อท้าย รอรูปอัปโหลดเสร็จ จึงกดส่งครั้งเดียว
ถ้าขั้นตอนไหนพลาด จะล้างกล่องคอมเมนต์ให้ ไม่ทิ้งข้อความค้างไว้

เพิ่มกฎได้หลายอัน เช่นแยกตามเรื่องหนัง แต่ละกฎมีรูป+ข้อความของตัวเอง
ระบบจะไล่จากกฎบนลงล่าง เจอกฎแรกที่ตรงแล้วใช้กฎนั้น

## ให้ AI ช่วยอ่านเนื้อหา (ทางเลือก)

คีย์เวิร์ดล้วน ๆ ตัดสินประโยคกำกวมไม่ได้ เช่น *"หาตั๋วหนัง SF ใครขายต่อบ้าง"*
มีทั้งคำฝั่งคนหาและคำฝั่งคนขายอยู่ในประโยคเดียว เปิดโหมด AI แล้วส่วนขยายจะส่ง
ข้อความโพสต์ไปให้ AI ตัดสินว่าผู้เขียน "กำลังหาตั๋ว" หรือ "กำลังขายตั๋ว"

**ตั้งค่า:** ป๊อปอัป → หัวข้อ **ให้ AI ช่วยอ่านเนื้อหา** → เลือกผู้ให้บริการ →
ใส่ API key → เลือกโหมด → **บันทึกการตั้งค่า**

### ผู้ให้บริการที่รองรับ

| ตัวเลือก | key เอามาจากไหน | โมเดลเริ่มต้น |
|---|---|---|
| **Google Gemini** (ค่าเริ่มต้น) | aistudio.google.com → Get API key — **key ตัวเดียวกับที่ใส่ใน Antigravity** | `gemini-2.5-flash` |
| OpenAI | platform.openai.com → API keys (คนละระบบกับ ChatGPT Plus) | `gpt-4o-mini` |
| อื่น ๆ | บริการใดก็ได้ที่รับรูปแบบ OpenAI chat completions — ใส่ URL เอง | ระบุเอง |

> **Antigravity ไม่ได้ออก API key ของตัวเอง** — key ที่ใช้ได้ต้องมาจาก
> aistudio.google.com/apikey และ **ขึ้นต้นด้วย `AIza`** เท่านั้น
>
> ถ้า token ที่คุณมีขึ้นต้นด้วย `AQ.` หรือ `ya29.` นั่นคือ OAuth token ของบัญชี Google
> (แบบที่ Antigravity ใช้ล็อกอิน) ซึ่ง endpoint นี้ไม่รับ — ส่วนขยายจะเตือนให้ทันทีที่พิมพ์
>
> `gemini-2.5-flash` มี free tier ใช้ได้โดยไม่ต้องผูกบัตร
>
> ถ้า key ที่คุณมีเป็นของเจ้าอื่น เลือกในดรอปดาวน์ **ผู้ให้บริการ** ได้
> โหมด "อื่น ๆ" จะขอสิทธิ์เข้าถึงโดเมนตอนกดบันทึก (Chrome จะเด้งถาม)

| โหมด | ทำอะไร | เรียก AI เมื่อไหร่ |
|---|---|---|
| ปิด | ใช้คีย์เวิร์ดอย่างเดียว | ไม่เรียก |
| ตรวจซ้ำ | กันคอมเมนต์ผิดคน | เฉพาะโพสต์ที่คีย์เวิร์ดจับได้ |
| ช่วยอ่าน | จับได้กว้างที่สุด | โพสต์ที่คีย์เวิร์ดจับได้ **และ** โพสต์ที่พูดถึงตั๋ว/โรงหนังแต่คีย์เวิร์ดไม่ตรง |

ปุ่ม **ทดสอบกับ AI** ให้วางข้อความโพสต์จริงแล้วดูว่าจะตัดสินยังไง ก่อนเปิดใช้จริง

**โมเดล** — ช่องโมเดลเป็นช่องพิมพ์ มีรายการแนะนำให้เลือก ใส่ชื่อรุ่นอื่นเองได้
ถ้าบัญชีคุณเข้าถึงรุ่นใหม่กว่า ไม่ต้องรอแก้โค้ด

**ค่าใช้จ่าย** — ราว 300 token เข้า + 100 token ออกต่อโพสต์ ตกหลักเศษสตางค์ต่อโพสต์
ในทุกรุ่นที่แนะนำ ระบบมีตัวช่วยคุมอยู่แล้ว:

- แคชผลไว้ เจอข้อความเดิมซ้ำไม่เสียเงินอีก
- เพดาน **เรียก AI สูงสุดต่อรอบ** (ค่าเริ่มต้น 60 ครั้ง)
- คัดกรองด้วยคีย์เวิร์ดก่อนเสมอ โพสต์ที่ไม่มีคำว่าตั๋ว/บัตร/โรงหนังจะไม่ถูกส่งไป AI
- ช่อง **ใช้ไปแล้ว** ในป๊อปอัปแสดงจำนวนครั้งและยอดเงินสะสม (ประมาณการเท่านั้น ราคาจริงดูหน้า pricing ของแต่ละเจ้า)

API key เก็บใน `chrome.storage.local` ของเครื่องนี้ (ไม่ได้เข้ารหัส) และถูกใช้จาก
service worker เท่านั้น จึงไม่หลุดเข้าไปใน context ของหน้า Facebook

## ถามราคาจาก MR.MOO (ทางเลือก)

เปิดในหน้าตั้งค่าหัวข้อ **ถามราคาจาก MR.MOO** — ก่อนคอมเมนต์ ส่วนขยายจะยิงไปถาม
ราคาตั๋วและป๊อปคอร์นของสาขาที่ลูกค้าพูดถึง แล้วเอา *ข้อความที่เซิร์ฟเวอร์ประกอบมาให้*
ไปคอมเมนต์ (ไม่ได้คำนวณราคาเองในเครื่อง)

| ช่อง | ใส่อะไร |
|---|---|
| URL ของ API | `https://api-mrmoomovie.siristudiophoto.com/api/v1` (ใส่ถึง `/api/v1` พอ) |
| API key | ค่าเดียวกับ `ExtensionApi__ApiKey` ที่ตั้งไว้บนเซิร์ฟเวอร์ |
| เอาข้อความราคาไปทำอะไร | ต่อท้ายข้อความของกฎ หรือใช้ข้อความราคาอย่างเดียว |
| รอ API ไม่เกิน | ค่าเริ่มต้น 8 วินาที |

ขั้นตอน: กรอก URL + key → กด **ขอสิทธิ์เข้าถึง API** (Chrome จะถามครั้งเดียว) →
กด **ทดสอบ** เพื่อดูข้อความจริงที่จะโพสต์ → กด **บันทึกการตั้งค่า**

ข้อควรรู้:

- ชื่อสาขา/ชื่อหนังที่ส่งไปถามมาจากผล **AI** เท่านั้น ถ้าปิดโหมด AI ไว้จะไม่มีชื่อสาขาให้ส่ง
  ข้อความที่ได้กลับมาจะกลายเป็นการถามสาขากลับ ("ขอทราบสาขาที่สะดวกด้วยครับ")
- ถ้า API ล่ม ตอบช้า หรือ key ผิด ส่วนขยาย**ยังคอมเมนต์ข้อความเดิมของกฎตามปกติ** ไม่ล้มทั้งรอบ
- คำพูดในคอมเมนต์แก้ที่เซิร์ฟเวอร์ ไม่ต้องอัปเดตส่วนขยาย

## ใช้งาน

1. เปิดหน้ากลุ่ม Facebook (`facebook.com/groups/...`)
2. จะเห็นแผงควบคุมลอยมุมขวาล่าง (ลากย้ายได้)
3. กด **เริ่มสแกน** หรือกด `Alt + Shift + S`
4. ส่วนขยายจะเลื่อนฟีดเอง เจอโพสต์ตรงเงื่อนไขจะไฮไลต์กรอบเหลือง แล้ว
   - โหมดยืนยันก่อนส่ง → ขึ้นกล่องให้เลือก **ส่งเลย / ข้าม / หยุด**
     (ไม่ตอบใน 60 วิ = พักโพสต์นั้นไว้ ยังเจอใหม่ได้รอบหน้า ต่างจากการกด "ข้าม" ที่ตัดถาวร)
   - โหมดออโต้ → คอมเมนต์ให้เลย
5. กด **หยุด** หรือ `Alt + Shift + S` อีกครั้งเพื่อหยุด

## ทำงานเบื้องหลัง + วนหลายกลุ่ม

### ทำไมต้องออกแบบพิเศษ

Chrome หน่วง `setTimeout` ของแท็บที่ถูกซ่อนเหลือราว 1 ครั้ง/นาที ถ้าปล่อยให้
สคริปต์ในหน้าจับเวลาเอง พอสลับไปแท็บอื่นการสแกนจะหยุดนิ่ง ส่วนขยายนี้จึงย้าย
ตัวจับจังหวะไปไว้ที่ service worker แล้วส่งคำสั่งเข้าไปแทน — ข้อความจากส่วนขยาย
ถึงสคริปต์ในหน้าไม่โดนหน่วง จึงทำงานต่อได้แม้ไปเปิดโปรแกรมอื่น

service worker เองถูก Chrome ปิดเมื่อว่าง 30 วินาที จึงตั้ง alarm ทุกครึ่งนาที
ไว้ปลุกให้กลับมาตั้งตัวจับจังหวะใหม่

### สองโหมด

**แท็บเดียว วนทีละกลุ่ม** — ติ๊ก "แท็บเดียว วนไปทีละกลุ่ม" แล้วกด "เริ่มสแกน"
พอครบเวลาหรือฟีดหมด จะพาแท็บเดิมไปกลุ่มถัดไปเอง แล้ววนกลับกลุ่มแรกเมื่อครบรอบ

**เปิดทุกกลุ่มพร้อมกัน** — กดปุ่ม "เปิดทุกกลุ่มพร้อมกัน" จะเปิดแท็บละกลุ่ม
(สูงสุดตามที่ตั้งใน "เปิดพร้อมกันสูงสุด" ค่าเริ่มต้น 10) ทุกแท็บสแกนไปพร้อมกัน
กวาดได้เร็วกว่ามาก แต่กินแรมและซีพียูตามจำนวนแท็บ

ปุ่ม **หยุด + ปิดแท็บ** สั่งหยุดทุกแท็บและปิดแท็บที่ส่วนขยายเปิดให้

### โควตาใช้ร่วมกันทุกแท็บ

**สำคัญ** — ตัวนับคอมเมนต์อยู่ที่ service worker ที่เดียว ทุกแท็บต้องมาขอสิทธิ์
ก่อนคอมเมนต์ทุกครั้ง เปิด 10 กลุ่มก็ยังคอมเมนต์รวมไม่เกิน `คอมเมนต์สูงสุด/ชั่วโมง`
ที่ตั้งไว้ ถ้าไม่ทำแบบนี้ แต่ละแท็บจะนับของตัวเองแล้วอัตราคอมเมนต์รวมจะเป็น
10 เท่า ซึ่งเกือบแน่นอนว่าบัญชีจะโดนจำกัด

> โหมด "ยืนยันก่อนส่ง" ใช้กับหลายแท็บได้ไม่สะดวก เพราะกล่องยืนยันจะไปโผล่ใน
> แท็บที่คุณมองไม่เห็น และหมดเวลาไปเอง — เปิดหลายกลุ่มควรคู่กับโหมดส่งอัตโนมัติ
> และตั้งเว้นระยะให้สูง

### รีเฟรชเมื่อเลื่อนถึงของเก่า

ตั้ง **"เจอโพสต์เก่ากว่า (วัน) แล้วรีเฟรช"** (ค่าเริ่มต้น 2 วัน) เมื่อเลื่อนลงไป
เจอโพสต์เก่ากว่านี้ติดกัน 3 อัน ถือว่าของใหม่หมดแล้ว จะรีเฟรชหน้าเพื่อกวาด
จากบนสุดใหม่ (หรือไปกลุ่มถัดไปถ้าเปิดโหมดวนกลุ่ม) ใส่ 0 เพื่อปิดพฤติกรรมนี้

เงื่อนไขที่ทำให้ย้าย/รีเฟรชมี 3 อย่าง อันไหนถึงก่อนใช้อันนั้น:
อายุโพสต์เกินเกณฑ์ · ครบเวลาต่อกลุ่ม · ไม่มีโพสต์ใหม่โหลดเพิ่มติดกันหลายครั้ง

## ตัวเลือกที่ควรรู้

| ตัวเลือก | ความหมาย |
|---|---|
| ส่งคอมเมนต์อัตโนมัติ | ปิด = ถามก่อนทุกโพสต์ (แนะนำ) |
| ทำงานเฉพาะหน้ากลุ่ม | กันเผลอไปรันบนหน้าฟีดหลัก |
| ข้ามโพสต์ที่เคยคอมเมนต์แล้ว | กันคอมเมนต์ซ้ำโพสต์เดิม |
| เว้นระยะขั้นต่ำ | หน่วงระหว่างคอมเมนต์ 2 ครั้ง (วินาที) |
| คอมเมนต์สูงสุด/ชั่วโมง, สูงสุดต่อรอบ | ถึงโควตาแล้วหยุดเอง |
| ข้ามโพสต์เก่ากว่า | ไม่ไปตอบโพสต์ค้างเก่า (0 = ไม่สนใจอายุ) |
| คำที่ห้ามเจอ | เจอคำพวกนี้ = ข้ามทันที เช่น `ขายตั๋ว` `ปล่อยตั๋ว` (โพสต์คนขาย ไม่ใช่คนหา) |

ส่วนขยายจำ ID โพสต์ที่จัดการไปแล้วไว้ ทำให้ไม่คอมเมนต์ซ้ำแม้จะสแกนใหม่
ล้างได้ด้วยปุ่ม **ล้างประวัติโพสต์**

## เจอโพสต์แล้วแต่มันเลื่อนผ่าน

เปิด **แสดงเหตุผลทุกครั้งที่ข้ามโพสต์** (เปิดไว้เป็นค่าเริ่มต้น) แล้วดูในกล่อง log
ของแผงควบคุม จะบอกเหตุผลตรง ๆ สาเหตุที่พบบ่อย:

| ข้อความใน log | แปลว่า | แก้ยังไง |
|---|---|---|
| ติดคำฝั่งคนขาย "..." | มีคำใน **คำที่ห้ามเจอ** อยู่ในโพสต์ | ลบคำนั้นออก หรือเปิดโหมด AI |
| เจอ "หาตั๋ว" แต่มี "..." ปนอยู่ ตัดสินไม่ได้ | ประโยคกำกวม มีทั้งคำคนหาและคนขาย | เปิดโหมด AI (**ตรวจซ้ำ** ขึ้นไป) |
| พูดถึงตั๋วแต่ไม่ตรงคีย์เวิร์ด | เขียนด้วยสำนวนที่ไม่มีในรายการคีย์เวิร์ด | เพิ่มคีย์เวิร์ด หรือเปิดโหมด **ช่วยอ่าน** |
| จัดการโพสต์นี้ไปแล้ว | เคยข้าม/คอมเมนต์โพสต์นี้ในรอบก่อน | กด **ล้างประวัติโพสต์** |
| โพสต์เก่า N ชม. | เกิน **ข้ามโพสต์เก่ากว่า** | เพิ่มค่า หรือใส่ 0 |
| อ่านข้อความโพสต์ไม่ได้ | DOM ของ Facebook เปลี่ยน | แก้ `MESSAGE_SEL` ใน content.js |

> คำว่า `ขายต่อ` ถูกถอดออกจากรายการคำต้องห้ามเริ่มต้นแล้ว เพราะคนหาตั๋วมักเขียนว่า
> *"ใครขายต่อบ้าง"* ซึ่งเดิมโดนบล็อกทิ้งทั้งที่เป็นลูกค้า

## เมื่อมันไม่ทำงาน

Facebook เปลี่ยน DOM/ป้ายกำกับบ่อย ถ้าเจอปัญหา:

- **"เปิดกล่องคอมเมนต์ไม่ได้"** — ป้าย aria-label ของปุ่มคอมเมนต์เปลี่ยน
  แก้ที่ `COMMENT_BTN_RE` / `COMMENT_BOX_RE` ใน [src/content.js](src/content.js)
- **"อัปโหลดรูปไม่สำเร็จ"** — ตัวตรวจ preview ไม่เจอ thumbnail
  แก้ที่ `waitAttachment()` ใน [src/content.js](src/content.js)
- **สแกนไม่เจอโพสต์เลย** — ตัวเลือก DOM ของข้อความโพสต์เปลี่ยน
  แก้ที่ `MESSAGE_SEL` ใน [src/content.js](src/content.js)
- **แผงควบคุมหาย** — รีเฟรชหน้า (แผงจะกลับมาเองภายใน 3 วินาที)

เปิด DevTools (F12) → Console ดู error ได้ ระบบจะพิมพ์เหตุผลที่ข้าม/ล้มเหลว
ลงในกล่อง log ของแผงควบคุมด้วย
